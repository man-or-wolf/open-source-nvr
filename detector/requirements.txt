# Pick the TFLite runtime by platform. Coral needs libedgetpu1-std installed on the host (see README).
# tflite-runtime (Python <= 3.11, x86_64) is the one the Edge TPU delegate is known to work with, and is built
# against numpy 1.x. There is no tflite-runtime wheel for aarch64 or Python 3.12+, ai-edge-litert is used there
# (CPU works; the Edge TPU delegate is not verified with it).
numpy<2; python_version < "3.12"
numpy; python_version >= "3.12"
tflite-runtime; python_version < "3.12" and platform_machine != "aarch64"
ai-edge-litert; python_version >= "3.12" or platform_machine == "aarch64"
